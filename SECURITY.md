# Sicherheitsmeldungen

Bitte Sicherheitsprobleme über die private Meldung **Report a vulnerability** im
GitHub-Sicherheitsbereich dieses Repositories melden. Falls private Meldungen
gerade nicht verfügbar sind, ein allgemeines Issue ohne Exploit, private Adresse,
Token, Cookie oder personenbezogene Daten eröffnen und einen privaten Kanal erbitten.

Keine Zugangsdaten an öffentliche Issues anhängen. Falls ein Token veröffentlicht
wurde, auf der eigenen Instanz ersetzen und die App erneut koppeln. Eine
veröffentlichte X-Sitzung auf X widerrufen; nur eine Datei zu löschen genügt nicht.

Unterstützt wird zunächst die aktuelle öffentliche Beta. Dieses Projekt ist eine
persönliche selbst gehostete App und kein mandantenfähiger Gemeinschaftsserver.
